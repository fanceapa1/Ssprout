# 05 — UI shell

Status: **done** (UI shell row; tooltips/herbarium/mobile polish from phase 5 largely covered).

## What
- `src/ui/`: the DOM UI over the garden, driven only by the session controller (ADR 0050).
  - Timer panel: idle "Plant a session"; studying: task name, "Focus · 2 of 3" /
    "Break — water your iris", block + total remaining, the plan as a segmented brush line with
    progress and watered drops, Pause/End, Water (ink watering can) / Skip break, gentle cancel
    confirmation naming the plant, "Still with us?" after 30 min paused; rests to 20 % opacity
    after 4 s without pointer movement while focusing.
  - Planting sheet (ADR 0053): task (≤ 40), total time (numeral, slider, 25/50/90, tier words),
    recommended plans (radio cards), plant grid (locked tiers dimmed "Needs N min+", earned tier
    tinted) → placement mode (markers, swap markers with "Replace …? It will be pressed into your
    herbarium.") → Begin.
  - Corner menu: sound (wires `createGardenAudio`, unlock on gesture), floating timer
    (`surfaces.widget`, only when supported), Pressed Flowers book, Garden data (export/import
    with readable errors + confirmation), Hints (ⓘ, all tips incl. learned).
  - Tooltips from the core registry: max two, one per region, inline inside sheets on phones;
    quiet line for completion ("Your Wood Violet for “Biology ch. 4” has bloomed.") and fauna
    arrivals (ADR 0054); hover/tap labels on finished plants (task · minutes · date).
  - Washi slips, seal button and grain generated as seeded SVG/PNG (ADR 0052); ink SVG icons;
    Shippori Mincho + Cormorant Garamond via @fontsource; reduced motion respected.
- `src/dev/`: `fixture-species.ts` (`?fixtures`, ADR 0055), `ui-debug.ts` (`sprout.ui.*`,
  `sprout.advance(ms)`, `?widget=fake`, `?uitime=`).
- `main.ts`: creates audio, timer surfaces (widget task) and the UI; installs widget/UI debug.
- Tests: unit (`format`, `plan-line`, `plant-labels`, `previews`), e2e `ui-session.spec.ts` (9)
  and `ui-menu.spec.ts` (7) — sheet/locks/compatible markers, begin/pause, cancel, break → water →
  skip, long pause, completion line + hover label, swap → herbarium, reload mid-session, keyboard
  placement, tips → retire → ⓘ, sound persistence, widget button, export/import round trip,
  fauna line, resting panel, phone viewport.
- Screens reviewed over four rounds (`artifacts/shots/r1…r4-*`): fixed a leader line crossing
  the panel, see-through slips, airy seal lettering → hanko frame, tips over content on phones,
  cramped placement bar, quiet line ghosting under placement, selected-spot ring.

## Why (non-obvious)
ADRs 0050–0055. The flow changed mid-task (ADR 0003: plant chosen at start); the end-of-session
picker and seed packet were dropped.

## Notes for others
- `tests/e2e/core-loop.spec.ts` (corrupt save): added a `flush()` before writing the corrupt
  value — the widget's notification sync now schedules a save at boot (headless Chromium reports
  `denied`), which `pagehide` flushed over the test's corrupt value.
- The UI never writes state by itself at boot (silent creatures such as striders are no longer
  recorded); keep it that way so loads stay side-effect free.
